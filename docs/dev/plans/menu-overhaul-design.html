2. Menu taxonomycommands and navigation jumps only, never every parameter

Green items run a command from the registry; plain items jump the navigator and inspector to a root. Check marks mirror checked(state); grey items are enabled(state) == False. Long jobs (render, separate, backup) open the in-window loading screen.

  • Every expanded header and leaf is in one global focus ring.
  • Reaching "font size" on an overlay card means scrolling past settings, project, and every layer.
  • Commands (Render, Add Layer, Apply Timeline Preset) are rows mixed among values.

Proposed: menu + navigator + inspector

FileProjectLayersRenderTimelineSettingsHelp
  • Navigator stays shallow: Settings, Project, Render children, Layers, Song markers.
  • Inspector shows one object's fields, with collapsible groups that do not join a global ring.
  • SectionNode / ExpandSectionDef stay as data for "which fields belong to which object", no longer as navigation.
