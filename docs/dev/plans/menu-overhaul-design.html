2. Menu taxonomycommands and navigation jumps only, never every parameter

Items run a command from the registry or jump the navigator and inspector to a root. Check marks mirror checked(state); grey items are enabled(state) == False. Long jobs (render, separate, backup) open the in-window loading screen.

7. Buttons, dialogs, and inline editorsopen the views below

The rule: the inspector holds live properties. Commands are real buttons. A command that needs parameters opens one dialog, and its label ends in "...". Nothing in the inspector waits for a later Apply.

Keyboard in a dialog

  • Up/Down or Tab move through fields, then the buttons.
  • Left/Right change a field, or move between buttons.
  • Enter runs the focused button. On a field it runs the confirm button, except on destructive dialogs.
  • Esc cancels and restores the values from when the dialog opened.
  • Inspector button rows: Left/Right pick a button, Enter runs it.
