3. Focus Scopes, Command Registry & Mouse Hit-Test Pipeline Keyboard-first in Phases 1–3, Mouse-ready in Phase 4

Input Dispatch & Focus Scopes

input_dispatch.py keeps global keys (Ctrl+Q, h, recording) and modals on top, then routes context keys by active scope:

  • Menu Bar: F10 / Alt focuses; arrows navigate; Enter triggers Command.run(controls).
  • Navigator: Up/Down moves; Enter selects object and populates Inspector.
  • Inspector: Up/Down moves fields; Left/Right calls existing RowSpec.apply_horizontal.
  • Timeline Strip: Existing TimelineFocus keymap.

Command Registry

Global actions migrate out of tree rows into a central registry under cleave/viz/:

  • Fields: id, label, menu_path, shortcut
  • Predicates: enabled(state) -> bool, checked(state) -> bool
  • Execution: run(controls) -> None
  • Shared by top Menu Bar items, direct shortcut keys, and the h Help overlay.

Shared LayoutItem Rects (Mouse Phase 4)

Every layout pass outputs LayoutItem(id, rect, role) in panel coordinates:

  • role="menu_item": Click opens menu or invokes command.
  • role="tree_node": Click focuses Navigator and selects object.
  • role="field": Click focuses row; horizontal drag scrubs VALUE_STEP via apply_horizontal.
  • role="splitter": Drag adjusts Navigator / Inspector column width.
