libprojectM (projectM Music Visualizer)
========================================

Shipped binaries
----------------

- projectM-4.dll (core renderer)
- projectM-4-playlist.dll (playlist helper; depends on projectM-4.dll)

Version: 4.2.0 (embedded in projectM-4.dll; Cleave requires libprojectM 4.2+).
Source commit: eae22de40144ee8ded92f3c04b93a4c2f82adcc0 (projectM master,
2026-10-13; 4.2.0 has no upstream release yet).

Upstream
--------

- Project: https://github.com/projectM-visualizer/projectm
- License: GNU Lesser General Public License v2.1 (LGPL-2.1); full text in LICENSE.txt
- Source for this build: projectM master at the commit above, via a vcpkg
  overlay of the `projectm` port (the port itself only ships release 4.1.8)

Build recipe (maintainer)
-------------------------

- Toolchain: Visual Studio 2022, x64
- Package manager: vcpkg triplet `x64-windows` (shared / DLL)
- The port builds the playlist library by default (ENABLE_PLAYLIST=ON); no
  feature flag is needed.
- Overlay port: packaging/windows/vcpkg-overlay/projectm/ in this repo. It is
  vcpkg's `projectm` port with REF pinned to the commit above, SHA512 set to
  that commit's GitHub archive, the macOS-only `macos-pkgconfig.patch` removed
  (it no longer applies to master), and "version" set to "4.2.0".
- Install command used (vcpkg in C:\src\vcpkg, repo checked out in WSL):
  `vcpkg install projectm:x64-windows --overlay-ports=\\wsl.localhost\<distro>\home\fernpa\cleave\packaging\windows\vcpkg-overlay`
- Copy `projectM-4.dll` and `projectM-4-playlist.dll` from
  `installed\x64-windows\bin\` into packaging/windows/

After copying new DLLs, list their imports with `dumpbin /dependents` (Developer
PowerShell for VS 2022) or `objdump -p <dll> | grep "DLL Name"` from WSL. Ship
any non-system dependency DLLs beside cleave.exe in the freeze output (zlib is
common on some vcpkg builds; the DLLs currently in this tree only require the
MSVC CRT and Windows system DLLs).

Visual C++ Redistributable (VS 2022 x64) is required on tester machines unless
app-local vcruntime/msvcp copies are added to the onedir root.
